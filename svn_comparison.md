1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
2. Можно ли в SVN сделать коммит без интернета? Почему?
3. В каких сценариях SVN до сих пор может быть предпочтительнее Git? 

1. - В SVN ветка создаёт отдельную копию репозитория, требуя связи с сервером, а в Git ветка является обычной ссылкой на локальный коммит 
2. - Нет, так как коммиты в SVN создаются только через центральный репозиторий, для соединения с которым требуется интернет 
3. - При необходимости жестко централизованного контроля над репозиторием с системой разделения прав
